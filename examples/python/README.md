# Python examples

Start with **`quickstart.ipynb`** (or `quickstart.py` — same walkthrough, no flags).

- `duckbox_client.py` — `connect()` / `.query()` → pandas
- `query_cli.py` — one-shot SQL with `--sql` / `--params`
- `isolation_check.py` — tiny tenant-isolation assert

Defaults: `grpc://127.0.0.1:4747` and `policies/ducklake/analyst.yaml`.
